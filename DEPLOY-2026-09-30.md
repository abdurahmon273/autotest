# Deploy — 2026-09-30

Ushbu push bilan serverga o‘tkazilgan o‘zgarishlar va serverda bajarilishi shart bo‘lgan ishlar.

## Nima o‘zgardi

- **Uy vazifasi (homework) moduli** — admin tomonida vazifa yaratish, student tomonida bajarish, muddat tugaganda avtomatik yakunlash (`FinishTaskJob`, queue orqali) va guruh Telegram chatiga xabar yuborish.
- **Yangi migratsiyalar** — `tasks`, `homeworks` jadvallari; `groups` jadvaliga `telegram_chat_id` ustuni.
- **Yangi paket** — `barryvdh/laravel-dompdf` (composer).
- **Login sahifalari** — parol maydonida ko‘z tugmasi (ko‘rsatish / yashirish), user loginda “Eslab qolish” checkbox (avval doim yoqilgan edi).
- **Landing sahifa** — yangi dizayn: ko‘k blok olib tashlandi, moslashuvchan (fluid) o‘lchamlar, Admin tugmasi yo‘q, statistika: Guruhlar / Ustozlar / Studentlar / Savollar.
- **Xatolar Telegram kanaliga** — `telegram` log kanali (`app/Logging/`), `error` va undan yuqori darajadagi xatolar botga yuboriladi.
- **Seed** — admin/teacher/student login-parollari `.env` ga bog‘liq emas, doimiy.
- **Ilova nomi** — `AutoTest` → `Prava Center` (`APP_NAME` orqali).

## Serverda bajariladigan ishlar (tartib bilan)

### 1. Kod va paketlar
```bash
cd /var/www/autotest
git pull
composer install --no-dev --optimize-autoloader
npm ci && npm run build
```

### 2. Migratsiya
```bash
php artisan migrate --force
```

### 3. `.env` ga qo‘shish / o‘zgartirish
```
APP_NAME="Prava Center"

LOG_STACK=daily,telegram
TELEGRAM_LOG_BOT_TOKEN=<bot token>
TELEGRAM_LOG_CHAT_ID=<kanal yoki chat id>
TELEGRAM_LOG_LEVEL=error
```
Bot kanalga **admin** qilib qo‘shilgan bo‘lishi kerak. Kanal id `-100...` ko‘rinishida bo‘ladi.

### 4. Kesh
```bash
php artisan config:cache && php artisan route:cache && php artisan view:cache
```

### 5. Queue worker (yangi, majburiy)
Homework muddati va Telegram xabarlari navbat orqali ishlaydi. Supervisor konfigi `/etc/supervisor/conf.d/autotest-worker.conf`:
```ini
[program:autotest-worker]
command=php /var/www/autotest/artisan queue:work --sleep=3 --tries=3 --max-time=3600
directory=/var/www/autotest
user=www-data
autostart=true
autorestart=true
numprocs=1
redirect_stderr=true
stdout_logfile=/var/www/autotest/storage/logs/worker.log
```
```bash
sudo supervisorctl reread && sudo supervisorctl update && sudo supervisorctl start autotest-worker
```
Har keyingi deploydan keyin: `php artisan queue:restart`.

### 6. Seed (agar admin parolini yangilash kerak bo‘lsa)
```bash
php artisan db:seed --class=UserSeeder --force
```
Login: `admin@autotest.uz` / `admin123` (`/admin/login`), `teacher` / `teacher123`, `student` / `student123` (`/login`).

Brauzerda: `/` (landing, nom “Prava Center”), `/login` (ko‘z tugmasi + Eslab qolish), `/admin/login`, admin panelda Uy vazifalari bo‘limi.
